# Kleinian Fractals

This is a project I worked on mostly in December 2005 and January 2006,
with a small amount of work carrying over into 2007 and possibly 2008.
I stopped working on it mainly because the next logical step I wanted to
do was beyond the capabilities of the framework developed here.

The code is written entirely in the PostScript programming language.
The various examples themselves can be run using GhostScript, but the
methods of invocation may not be obvious, so beware.  *Note:* nothing in this
code base should ever be sent directly to a printer, even (especially!)
those files with names ending in `.ps`.

I wrote this code before I had any experience with professional
software development.  In particular, I didn't know about version
control.  Also, the code is not particularly readable, even for
PostScript.  The lack of version control is obviously fixed now, but
considering this to be mainly a historical code base, I make no promise
that the code quality will ever be significantly improved.

As for the fractals themselves: alas, I can't *really* take credit for
most of the fractals as defined mathematically.  Some of them were
taken from or inspired by the book
[Indra's Pearls][http://klein.math.okstate.edu/IndrasPearls/]
by Mumford, Series, and Wright.  Others were reverse-engineered from
illustrations in long-forgotten math papers or other work.

The uniting characteristic of all the fractals is Kleinian groups.
Specifically, the symmetry group of each fractal (appropriately defined)
is Kleinian.
